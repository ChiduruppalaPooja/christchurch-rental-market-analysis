# Christchurch Rental Market Analysis

An academic team project analysing the Christchurch rental market using data science, statistical analysis, and geospatial techniques to identify rental trends, affordability patterns, and housing market insights.

---

## Project Overview

This project explores the Christchurch rental housing market using publicly available datasets. The objective is to identify trends in rental prices, examine affordability across suburbs, and understand the factors influencing the rental market through data analysis and visualisation.

The project follows a reproducible data science workflow, including data collection, cleaning, exploratory analysis, statistical analysis, and geospatial mapping.

---

## Objectives

- Clean and preprocess rental market datasets
- Perform exploratory data analysis (EDA)
- Analyse rental price trends across Christchurch
- Assess affordability across different suburbs
- Create statistical summaries and visualisations
- Generate geospatial maps to identify spatial patterns

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/<username>/christchurch-rental-market-analysis.git
```

2. Open the project in **RStudio**.

3. Install the required packages.

```r
install.packages(c(
  "tidyverse",
  "ggplot2",
  "sf",
  "dplyr",
  "tidyr"
))
```

4. Run the analysis scripts in the `scripts/` folder.
